# Changelog

## 0.1.7

Первая версия, подготовленная для хранения через GitHub.

Функционально соответствует 0.1.6:

- вкладки Основное / Способности / Инвентарь / Заклинания / Навыки;
- базовые данные Actor;
- embedded Items;
- отдельные списки оружия, снаряжения и расходников;
- способности и заклинания разделяются категорией;
- базовый список навыков.

Дополнительно:

- добавлен `.gitignore`;
- добавлен `CHANGELOG.md`;
- в `system.json` добавлен адрес репозитория GitHub.
