# Быстрая НРИ 6.2 — Foundry VTT 14

Первая минимальная сборка системы.

## Установка

1. Остановите Foundry VTT.
2. Распакуйте папку `fast-nri` в:
   `Data/systems/`
3. Итоговый файл должен лежать здесь:
   `Data/systems/fast-nri/system.json`
4. Запустите Foundry.
5. В Setup → Game Systems должна появиться `Быстрая НРИ 6.2`.
6. Создайте новый World с этой системой.
7. В мире создайте Actor типа `Персонаж`.

## Первая проверка

Откройте F12 → Console. Должны появиться:

- `Быстрая НРИ 6.2 | Инициализация системы`
- `Быстрая НРИ 6.2 | Система готова`

На листе Actor измените:

- HP;
- скорость;
- Куб боя;
- три КЗ;
- защиты;
- Движение;
- Воздействие;
- Вмешательство;
- классовый ресурс.

Закройте и снова откройте лист — данные должны сохраниться.

## Что уже есть

- Actor: `character`, `creature`;
- Item: `weapon`, `ability`, `equipment`, `consumable`;
- базовые System Data Models;
- ActorSheetV2 и ItemSheetV2;
- trackable HP, классовый ресурс и Д/В/Вм.

## Изменения 0.1.3

Исправления ApplicationV2:
- `tag: "form"` задаётся в DEFAULT_OPTIONS;
- удалены вложенные `<form>` из Handlebars;
- drop слушается непосредственно на `.fast-nri-drop-zone`;
- само создание Item делегируется штатному `ActorSheetV2._onDrop`;
- добавлена диагностика DROP в Console;
- добавлены кнопки создания embedded Item прямо из Actor Sheet.

### Диагностика

При открытии Actor Sheet в F12 Console должна быть строка:

`Быстрая НРИ | Лист Actor готов: <имя>`

При перетаскивании Item в пунктирную зону:

`Быстрая НРИ | DROP получен ...`

а затем:

`Быстрая НРИ | DROP обработан ActorSheetV2`

Если возникает ошибка, она выводится как:

`Быстрая НРИ | Ошибка DROP`

Исправление прокрутки Actor Sheet:

- добавлен штатный класс Foundry `standard-form`;
- убрана попытка делать root PART `scrollable`;
- `.window-content` теперь является единственной вертикальной scroll-областью;
- внутренний `.fast-nri-sheet` имеет естественную высоту и больше не обрезает содержимое;

После установки обязательно выполнить `Ctrl+F5`.


## Изменения 0.1.6

Карточка Actor разделена на пять вкладок:

1. Основное
2. Способности
3. Инвентарь
4. Заклинания

- поле `system.category` разделяет обычную способность и заклинание;
- добавлены кнопки создания Item прямо в соответствующих вкладках;
- инвентарь разделён на оружие, снаряжение и расходники;
- добавлены 15 базовых навыков;
- навыки пока редактируются вручную через значения d4/d6/d8/d10/d12;
- активная вкладка сохраняется при перерисовке открытого листа;
- drop-зоны работают на вкладках Items.
