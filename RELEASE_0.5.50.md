# Fast NRI Foundry 0.5.50 — rules 6.3 migration

Целевая редакция правил: **Быстрая НРИ 6.3**.

## Изменено

- системное название переключено с 6.2 на 6.3;
- Weapon Item получил `system.attackType`: `melee | ranged`;
- Ability `attackCheck` получил `attackType`: `melee | ranged | area`;
- тип исходной атаки сохраняется в Attack/Damage ChatMessage flags;
- системная Самозащита 6.3 выбирает характеристику по виду атаки:
  - Ближняя → Стойкость;
  - Дистанционная → Рефлекс;
- атака с Досягаемостью остаётся Ближней;
- Область действия не получает Самозащиту;
- Защита союзника продолжает использовать общую Стойкость;
- частное Защитное Ability может заменить характеристику Самозащиты;
- Actor получил редкое `selfDefenseCharacteristicOverride` для карточек существ;
- Фея Разлома одноразовой миграцией получает `reflex` как исключение своей карточки;
- старые Weapon/Ability Items получают машинный тип атаки одноразовой миграцией, если его можно определить однозначно;
- если legacy Ability нельзя определить однозначно, система не угадывает и просит разметить карточку вручную.

## Не входит в этот релиз

- миграция прегенов на 6.3;
- миграция simulator/AI;
- массовый импорт/пересборка Compendium;
- изменение остальных правил 6.3 вне уже принятого attack-type/Self Defense слоя.
